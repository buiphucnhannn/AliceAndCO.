## 2. DESIGN PHILOSOPHY & VISUAL IDENTITY

### 2.1 Aesthetic Theme: **Executive Luxury Consulting**
The landing page must convey world-class credibility, discretion, elegance, and professional authority—similar to top-tier advisory and legal consulting firms.

### 2.2 Color Palette
- **Deep Navy Blue (Primary / Backgrounds):** Represents stability, legal authority, and institutional trust (`#0a1128`, `#0f172a`, `#1e293b`).
- **Royal Gold (Accent / Highlights):** Represents prestige, premium service, and executive luxury (`#d4af37`, `#f59e0b`, `#eab308`, metallic gold gradients).
- **Crisp Neutrals:** Pure white, slate zinc, soft muted warm grays for immaculate typography readability.

### 2.3 Typography & Visuals
- **Font pairing:** Modern, high-legibility sans-serif with subtle editorial sophistication (e.g. Geist Sans / Inter combined with serif/refined accents if applicable).
- **Key Visuals:** High-resolution Saigon (HCMC) skyline, modern architecture, polished corporate environments, subtle golden sheen / glowing accents.

### 2.4 Language Requirement
- **100% English** across all public-facing elements (Nav, Hero, Sections, CTAs, Forms, Footer).

## 6. TECHNICAL STACK & ARCHITECTURE RULES

1. **Framework:** Next.js 16 (App Router) in `src/app`.
2. **Codebase Directory Layout:**
   - `src/app/`: Routing, layout, metadata, styles.
   - `src/components/`: Modular React components (`layout/`, `sections/`, `ui/`).
   - `src/data/content.js`: Single source of truth for text and data matching this specification.
   - `public/`: Static assets (SVGs, imagery, logos) at project root.
3. **Styling:** Tailwind CSS v4 configured with custom Navy & Gold color tokens.
4. **Responsiveness:** Flawless mobile, tablet, and desktop views.
5. **Performance & SEO:** OpenGraph tags, semantic HTML tags (`<header>`, `<main>`, `<section>`, `<footer>`), descriptive alt texts, high Core Web Vitals score.
